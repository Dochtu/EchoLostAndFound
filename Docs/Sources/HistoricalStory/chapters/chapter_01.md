# 第一章｜停走的怀表

从全篇开场约 3 分钟进入本章，本章约 8 分钟。目标是核定怀表的原主及接领对象，并在台账上决定它暂时放在哪里。目标时长用于节奏设计，交接不会因停留过久自动发生。

## 开场

画面先在失物招领处。风把雨推到玻璃上，日历页背后压着末班交接表。站内广播：「青禾站今晚完成最后一次值班交接。候车厅内侧可以通行。」玩家开印有「暴雨滞留／A-0641」的积压包，镜头停在怀表、带套和封着的票袋。先读表盘；带套和票袋可见，等后续登记流程开放。

老周站在候车大厅的清点桌边，林遥在西值班窗旁等叫号。

> 老周：「这封从旧库搬过两回。我来对号，你来签。先看表背，失物只认号。」
>
> 林遥：「公告上有一张我妈留的领取凭号。我把原来的带来了。表还在吗？」

## 场景、对象与取证

| 场景 | 对象 | 操作与结果 |
| --- | --- | --- |
| 失物招领处 | 怀表、A-0641 交接包、失物副联册 | 查表盘、背刻、编号与弯冠，得到 E01。选择「查同号单据」，在包底取 E03。翻柜台副联册同号档位取 E04。现场有相应的迭代提示「先记编号，随后对照单据」。 |
| 候车大厅 | 老周、交接箱签、西窗外的林遥 | 与老周聊雨夜时允许 B01 主观回忆；可帮他对箱签。林遥可提熟悉的刻字和领取凭号。「核对领件」为 D02，接受物证后可确定案号对应物。 |
| 站台 | 内侧维修柜、玻璃灯罩、台沿 | 按移交手册到内侧维修柜查 E02。顺背页索引翻 E05；现台沿有小缺口，仅为场景美术，F03 依当年的联和表来证。柜台道具边界止于安全隔绳。 |

## 固定对话和证据触发

| 情境 | 固定台词及范围 |
| --- | --- |
| 老周开场问照明，B01 | 「站台那晚在我印象里一直亮着。我还把那盏油灯拖到里头去了。」 |
| 将 E02 给老周，D01 | 「进水，二十一点十七。我的灯到二十才摆好。是黑过，中间那点我记混了。」 |
| 将 E01 和 E05 给老周，D03 | 「她抓住小姑娘的胳膊，表掉到台沿。我弯腰拣的时候指针已经不动了，冠头是歪的。」 |
| 林遥看到表时 | 「四月十二是我妈的生日，九月十六是我的。那个点，我小时候摸得到。柜里究竟是不是那一只，你得对上号。」 |
| 向林遥展示 E03 与 E04，D02 | 「沈禾，是我妈妈。这个号和她放在家里那张一样。她写着要我自己领。」 |
| 林遥拒绝再聊 | 「表的事按签单。别的今天先别问。」仍可执行「核对领件」。 |
| 模型离线或闲聊不识别 | 点「照明」「表背」「领件编号」分别播放上表允许段。对应证据缺失显示「先看维修柜」或「请把表号和两张单放在台面」。没有证据自动生成。 |

玩家可在板上核对 R01「沈禾原主、林遥可领」和 R02「灯黑与撞表同刻」。错误例「停电使怀表停了」应点明表是机械上链，并提示找拾物联；错把拾表人当原主则指向 QH-283 的交修及指定领件单。章节可以先做其中任何一条。

## 选择与章末

- A01「帮老周对三个箱签」是可选固定行动。三个箱签取同号核对即可，老周改用较少推托的固定过渡语「行，回头我给你腾柜台」。只记一次，关系变化不解锁证物。
- A02「暂交林遥」要求 R01 通过。先向林遥展示两张单作为 D02，签今夜暂存回执后由她把表收入衣袋。回执写明结案还可选择她签收、公开页去名后她签收、或按她本人今夜授权把表交回作受限封存；她仍留站等结案，不可提前离开。
- A02「装袋待核」可在 E01 后立即用。玩家把表摆回带案号的软衬袋。未做 R01 可暂挂、稍后查齐再取得终局领取资格。任一选择前证据照片存档，之后仍可做 R01/R02 或 D01/D03。

读过 E01 并登记 A02 即可进入第二章。玩家若在怀表上停很久，老周只提示「先记表在哪儿，也能查下一个物件」。没有自动忘记任何线索。结尾触发：招领处磁带套签从纸袋探出来，盒盖上露出「A 面」。老周把旧放音机推到灯下：「移交前，听一遍带子里还能听见什么。」
