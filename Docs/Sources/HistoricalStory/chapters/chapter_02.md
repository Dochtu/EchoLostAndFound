# 第二章｜没有寄出的录音带

目标时长约 8 分钟。确认哪两段原声仍在、谁用什么盖过另一段、许澄当时实际知道什么。玩家可以完成整条核对，也可以留待第三章回来查。

## 开场

失物台：胶片壳掀开一半，套签铅笔字留下三道竖划。推窗的风声盖过一次短促的马达启动声。许澄在大厅收自己的陈列盒，辨认字迹后停下来。

> 许澄：「那三笔是我画的，提醒自己从 A 面起头。我那阵什么都录，雨敲窗最好录。」
>
> 许澄：「中间那段……我以前一直当成车又开了的广播。拿来，我们听一遍。」

第二句为 B02，只在修正前使用；“又开了”始终是他的早年印象，没有车辆资产或字幕替他确认。

### 固定实物声音 E07

| 时间点 | 字幕与声源 |
| --- | --- |
| 00:00–00:01 | 背景雨声和轻微底噪。 |
| 00:02–00:07 | 原声女声：「阿遥，西窗等我。要是车停了……」随后突然截断。 |
| 00:08–00:25 | 后录男声：「留声机检音。大厅内侧通行，按值班指引。这里是青禾站。检音毕。」主体间留有说话间隔和马达声。 |
| 00:26–00:31 | 底噪再次衔接，原声女声：「……那张票收好。听见的话，别急。」 |

可读稿完整等价于检查过 A 面。B 面无登记留声。中段没有原声可播，设备没有还原功能。第三章的 21:30 时限出自纸质 E12，此处不在任何声道提示。

## 人物对话与触发

| 情境 | 固定台词及范围 |
| --- | --- |
| 许澄认套签 E06 给 E08 | 「我记下了谁坐在录音机前。她说阿遥的时候，我听见了；我刚去借耳机，她后面的话没进我耳朵。」 |
| 问林遥当晚的位置 | 「我记得东边那扇门。她写的是西窗，我没到那边去。我在东室等了很久，以为她会自己找过来。」她不见得知道西窗实际情况。 |
| 林遥 B03，玩家催她认错 | 「我当时没见着她。我一直觉得她没去西窗。你让我想起这事，跟你知道她去哪儿是两码事。」 |
| 把 E07、E08、E09 放在台上，许澄 D05 | 「我开机，听她说‘阿遥，西窗等我’就去借耳机了。拿耳机回来时原段已录完。我后来折回取写字夹，看见周叔按了录音键、读检音词。我以前以为那是开车广播。」许澄在案务纸签名，收 E10，撤下 B02 的未修正变体。 |
| 老周检音核对 D04 | 「她签字叫我盖掉私人去向。我从第八秒录到第二十五秒。其他两截留着，哪天该听，由她女儿决定。」 |
| R03 后先问林遥是否愿听，D04 | 「就放两头吧。如果那一段已经没有了，我还想听她把‘阿遥’说完。」听毕她把手放到空白处：「这两个字，我认得。」只给余声并用占位标签标示中段。 |
| 无模型或拒绝闲聊 | 「核对索引」「核对检音」「请本人选是否听」分别执行对应固定互动。若 E10 缺证，显示「先把原带余声、索引纸和第十四页摆齐」。本人仍完成必要的案务签认。 |

在板上合 E06、E07、E08、E09、E10，提交 R03。若误选实际复车广播，反馈「页上写检音占位，听到的声音只能证实录到带上」。若提出恢复私人原句，反馈「你找到的是覆盖动作和缘由；原来的说话没有留在这个区间」。玩家从 E09 知可核定沈禾同意保护家庭去向，许澄 E10 只证实按键和处理所见。

## 选择与章末

A03 选择「让林遥先听已核定余声」（需 R03，带来 D04 所列对话，更新她已听到的范围）或「先留文字，等她自己决定」（E07 后即可）。即使完成播放，公开授权也只适用于约定的去名案史；她听没听带都不改物权和处置门槛。选择可在第三章回到失物处更改，被听过的余声不能当作没听过。只更新有效的新行为。

E06、E07 都入档且完成 A03 后可进入第三章。未成 R03 时，柜台状态写「覆写待核」，玩家可带着它继续。镜头回到磁带纸封，铅笔的 0641 与旧票袋码相同。老周说：「票夹还封着。去大厅抄页找它，你会看见页码中间有个折口。」开启车票夹交互。
