# 第三章｜没有名字的车票

调查和处置约 12 分钟，最后演出约 3 分钟。找出无名票的使用者和缺页对应副联，证明母亲曾到西窗与母女没有接上是两件同时成立的事。最后决定自己有权限处理的三件原物及档案去向。

## 开场

失物招领处。雨速慢下来。玩家掀票夹，露出压号 0641。票样全价、不记名、无检票钳痕，有作废章。候车大厅西窗已关，隔玻璃仍可以翻旧查询簿。

> 老周：「票上没名，去找当晚的同号存根。要是查阅簿真缺了什么，就看挪交的位置。」
>
> 林遥：「我不是想问车到底开没开。那晚在西窗，她有来过吗？」
>
> 许澄：「我能认得的声音，只有我录过或真听见过的。别让我替纸上的人签名。」

林遥的开场问法不写入事实。即使玩家已猜中，签询证物才有回答资格。

## 取证流程

| 场景 | 对象 | 操作、证据及推进 |
| --- | --- | --- |
| 失物招领处 | 无名票、证据板、物品处置签发页 | 看压号、钳口、作废章取 E11。证据板保留第一和第二章所有卡片、音频文字和照片。读过 E11 与 E13 后可打开签发页，核验门槛后再定最终处置。 |
| 候车大厅 | 售票窗下柜、查询桌抄页、三位人物 | 凭 E11 的 0641 跨核存根，收到 E12：「20:54 备用约定」「21:13 调度停运」「0641 未检、阿遥使用」同档摘录。直接翻公开发车簿见划痕、夹页折口和 E13「21:52 原夹 12/13 → 受限柜 A-0641」。从查询桌的移交手册取得带遮挡副联的阅档许可。向三人分别用固定按钮核对相关关切。 |
| 站台 | 内侧档柜 A 槽、旧灯、隔绳 | 沿 E13 搜档号。在隔绳内侧抽受限阅档联 E14：东室「21:19 入、期间未离室、21:38 母方指定姨母签交离室」；西窗「21:27 沈禾，找 0641，本站窗未交接」。柜中只显示案内可用遮挡影印，未成年人住址、姨母姓名、其他乘客不显示。柜门标签能重复读，不需要 NPC 交钥匙。 |

## 核对与备用对话

| 情境 | 固定台词或动作 |
| --- | --- |
| 林遥 B03 尚未修正 | 「我一直以为她没去过西窗。我也没在那里等到她，我能记住的是东室。」若不愿闲聊可选「只核对两联」。 |
| 林遥收到 E12 与 E14，D06 | 她先把两张联分开看，再把 0641 对在同一行。「她那时候到西窗了。我那会儿在东室。分开以后，在西窗没碰上。」锁定修正，林遥当场写 E15：「次晨她来姨妈家，我问‘你后来怎么没来？’她说‘我去找你了。’我以为她是在站里找过，还是没往西窗那边去。搬走后我几回想问，又怕听她说确实没去。她四年前去世了，我没把问题问到西窗。」 |
| 老周只看到 E13 | 「抄页是给大厅查的。问缺页就顺编号找。你把两边的联拿齐，我再照原件核对。」 |
| 老周收到 E12、E13、E14，D07 | 「大厅抄页上的名字、去处是我划掉的。两张原夹副联是我挪入受限包的。小孩去向和临住处不能摆在大厅给人查。调度原令没动，东西值班正联按柜留底。」他当场签 E16。看见 E14 后可说「西窗这时我没在，签注在这儿：二十一点二十七。」 |
| 许澄收到 E12 的调度摘要，D08 | 「调度原令写的是停运。那晚没有恢复发车。我不能拿自己听见的声音作调度依据。」停用「可能复车」的旧信念，仅 D05 会提供亲历覆盖的证词和 E10。若 D05 已做，D08 只补充正式停运原因。 |
| 任一 NPC 拒绝闲聊、模型不可用或被输入诱导 | 保留在同一场景的「只核对两联」「核对缺页」「核对调度」按钮，校验证物后由本人按固定脚本签认；不足时提示去售票窗、查询桌或 A-0641 档柜。恶意输入没有签认效果。 |

A04 在 D06 前可先选「把西窗一句单独递给她」，林遥可以自己走到灯下展开签联，留一句「谢谢你让我自己看」。也可选「把两联一起放到核对台」，她直接对号签认。两条都只需 E12、E14，有相同事实、证据与结案资格。暂不询问也可做 R04。人物关系区别表现为回应和是否主动在终局接过台账，证据组合不依赖 A04。

## 推理与章节完成

1. 用 E11、E12、E14 完成 R04。「无名」的票和有名签联以票号及签验对应；21:27 到过西窗与 21:19–21:38 东室连续登记支持错过。21:27 并未证明母亲在西窗一直等到几点。
2. 用 E12、E13、E14、E16 完成 R05。玩家可选区分调度正本、查阅抄页和被移动的两张副联。错选「老周改过停运命令」提示看 QH/R/117 调度原令，错选「他销毁了回执」提示对比 A-0641 的号与夹页折口。
3. 全部 R01–R05 通过后按证据时间上板做 R06。把 21:17 的熄灯、坠表置于同一格；不要求判断一分钟内的先后。E15 是人物回忆，既不替代签询，也无须塞进这个暴雨夜排序。缺前章证据时按档案侧栏回对应地点，演员仍在。
4. 选择结案。首开签发页只需 E11 和 E13，结案有明确确认窗。提交归还或公开而缺证，显示按 R 编号列明的缺项与取证动作，下方可回去继续查或主动改选封存。关闭面板、退回探索、重复取证都不产生处置。无最低推理门槛的封存永远可选。签发一次后封结，不能重复生成签收或新档案。

## 三种结尾演出

| 选择与允许状态 | 演出、物品和档案 |
| --- | --- |
| 归还 END_RETURN，R01+R03+R04 | 私下在柜台签三件物的领取单。林遥把怀表包好、夹进票与带，问许澄：「等我想听的时候，你能教我换一根带轴吗？」许澄把手从播放键上移开：「你决定哪天。」若 D06 做过，林遥临走前看一眼西窗说「原来她是来过的」；未做则只说「领回单我签好了」。老周留西窗灯，到她出门才关。镜头给受限领回清单和空置三个存放位。 |
| 封存 END_SEAL，签发页无最低推理门槛 | 三件原物进可复核的受限箱，林遥若暂收表则自愿交回。林遥：「我想自己把盖子合上。」老周等她把手挪开再锁；许澄把机器停在收带位置。记录栏实际列「已核」与各缺项「待核」，让补证不足的封存结尾不会宣称母亲或录音的未知事实。箱封写案号、受限标记、复核入口。 |
| 公开 END_PUBLIC，仅 R06 | 怀表和票给林遥，许澄把录音原件按书面同意交站务档案。将去名副本交接给去往镇站史档案的资料盒，三人协作贴大厅里最后一张样页。老周在更正栏填「当班站务」并说「那页是我动的，这份我留下。」公开页文案：「暴雨导致末班停运，站台支路曾中断照明。临时分流使两位寻人者错过。查询抄页有涂改，两份交接副联仍在案。」公开页没有姓名、编号、住址、具体儿童路线、私密音轨及签迹。镜头从样页移到真正入档的受限盒，再听见大厅关灯。 |

结案的声画用现有三个场景、物品近景和站内环境声实现。公共页出现前，所有 NPC 自由交互结束。结尾结果保存在同一案号下，原作者确定的历史继续成立。
