# 暴雨夜真相时间线

全文为剧透。T-12 为十二年前暴雨夜，T0 为游戏当夜。表中时点以当地 24 小时制记录。站台的 21:17 由站务事故即时记录与配电故障卡对时，表盘读数再由拾表记录和实物复核。秒数仅用于录音带相对定位。

## 暴雨夜

| 时刻 | 实际发生 | 当时的人和物 | 留到今天的来源 |
| --- | --- | --- | --- |
| T-12 20:54 | 沈禾买票给女儿林遥乘末班车；把备用集合约定在双联票袋上写清：「阿遥，若末班停开，西值班窗等我。我九点半前回来接你。沈禾。」 | 林遥拿票 0641 和上联票袋。沈禾把写字时压出的下联留在售票窗，和未检改签联一同存档。沈禾把仍正常走动的怀表放在外衣口袋。 | E11 票与压号，E12 压写下联，林遥对旧票的回忆。 |
| 21:08 | 沈禾正要去门厅电话处联系妹妹，先托正在记录雨声的许澄在 A 面留下可以转交的口讯。 | 老周答应把消息留给林遥。许澄调好机器，听到开头后去设备柜借耳机，回来时已录完。老周留在柜台并听到全段。录音带此后一直在柜台盒内。 | E06 套签，E07 现存余声，E08 索引纸，E10 许澄固定陈述。 |
| 21:13 | 上游边坡滑塌封阻区间，调度 21:13 下令末班停运。原调度顺序号 QH/R/117，复栏为「本夜末班取消，未恢复」。大厅分区广播发送并撤下登车指示。 | 林遥随人群到站台内侧，沈禾打完电话后沿候车厅回寻找她，在站台内侧碰到她。两人因接下来的熄灯和现场分流短暂失开。 | E12 调度正本的留档摘录。 |
| 21:17 | 暴雨进水使站台照明支路跳闸。林遥踩滑，沈禾拉到她的肘弯，怀表从外衣口袋跌到内侧水泥台沿，侧冠磕凹。老周在旁听见撞击，拣表时借配电值守手电看见表盘停在 21:17。 | 沈禾被处置员指向大厅一侧帮忙导流，老周把林遥带到干处。沈禾以为下一步仍照原约到西窗，未看到林遥被带去东室。支路进水和坠表为同一分钟的两个事件。 | E01 表盘与撞痕，E02 故障记录，E05 现场防滑拾物联及同夜检点。 |
| 21:19 | 为避开挤到站台内侧的滞留乘客，老周将林遥带进候车厅东休息室，登记时用手中的票尾号 0641 核对。 | 林遥被告知接领人会来，原以为母亲办分流后会接到她。老周留票作停运签验，就近把取消票与拾表放入暂存包。东室交接记录使用同一票号关联接领。 | E11 作废票，E12 取消签验联，E14 交接联。 |
| 21:20 | 油灯照亮站台内侧通道。 | 老周以后回想时，将自己确实放过临时灯概括成「一直亮着」。油灯是局部光源，未恢复支路。 | E02 故障卡中的补照时点，E05 检查联，B01。 |
| 21:27 | 沈禾来到候车厅西值班窗，签「找 0641，沈禾」，此时仍在 21:30 的承诺时限内。登记员记录「本站窗未交接」。 | 沈禾在西窗核对留票人后被转回大厅等候通知。当时东西两处各在处理滞留人群，停电后仅供站务的联络本未及时合并。沈禾以为女儿可能已跟姨妈离站；姨妈是约定好的替代接领人。 | E14 西窗问询副联。该记录证明她到过西窗及问询对象。 |
| 21:30 | 西窗没有林遥，东室没有沈禾。东室交接联记「21:19 入／期间未离室／21:38 出」。 | 林遥从东室看不见西窗。柜台忙时未播放许澄代录的口讯，两处也没有在约定时刻对上号码。 | E14 双副联可交叉；E07 余声仅能帮玩家理解沈禾原本准备留声。 |
| 21:38 | 姨妈由指定入口接走林遥，回执「0641 实交接／母方指定姨母」并签名字。 | 当夜雨大，姨妈先带林遥回自己家。姨妈没有亲见西窗签询；她把接走通知留在东室，交接汇总后才由站务转达给沈禾。 | E14 东室原样摘录内的连续签交接。只保留母方指定姨母的关系，不公开其身份姓名。 |
| 21:43 | 沈禾从东室汇总得知林遥已随姨妈离开。临时安置关系到尚未对外说明的分居，签字请老周把会暴露临时去向的录音盖掉，保留两端可以留下的声音。老周从纪录索引 00:08 开始按录音，到 00:25 停止，以自己口述的检音词填过原段。 | 许澄在 21:08 借耳机回来时原留声已经录完，21:43 他又折回取写字夹，看见老周按键，听到老周口述，先前没听过被盖的内容。沈禾当面让录音带留站，日后由女儿决定是否听。许澄同意把这盘带作为失物附件留下；他在 21:08 启动录制，沈禾说完话后由老周停带。 | E07 剩余实际音轨，E08 当夜纸索引，E09 工作登记及沈禾签注，E10 目击陈述。 |
| 21:52 | 老周删改大厅查阅用的发车簿抄页里 0641 旁的乘客名与临时去向，将原本为汇总临时误夹于页后的两张副联转入受限包，以免外人顺着窗台抄页找到未成年乘客的临时住处。 | 大厅抄页保留「末班停运／0641」和移交编号，页码间留下折口。真实调度正本留在调度柜，东西两份值班正本按规定分柜保管。老周知道自己移动了回执，当夜未逐行读西窗签记。 | E12 调度正本，E13 公众抄页与索引，E14 受限包，E16 固定陈述。 |
| 22:03 | 老周在拾物联复核表的状态，记「表冠凹、冠轴侧弯；轻试传动卡滞，未拆修」并贴停用。 | 早些时候老周在站内兼做小五金维修。拾表后的停机机理用当夜检点与现在仍可观察的痕迹共同判定。 | E05 原页、E01 实物。 |

## 事后与今天

| 时点 | 发生的事 | 可见来源 |
| --- | --- | --- |
| 次日清晨 | 沈禾到姨妈家接林遥。林遥问「你后来怎么没来？」她指母亲没到东休息室接到自己，也想着西窗原约。沈禾答「我去找你了」，她指依约去了西窗，在场面混乱时没能接成。林遥只听成母亲留站找过，仍认为母亲在分流后选择先办搬离的事。分居迁出在当周办完。多年后林遥拿起过那张领取凭号，几次想问「你那晚回过西窗吗」，却怕听见自己当时不值得妈妈等，将凭号收回抽屉。母女关系此后有过亲近，西窗仍是她避着的问题。沈禾以为女儿在问没接到她这件事，没听过女儿认定她连西窗也没去。 | E15 有权限的林遥回忆支持对话与后来的想法。沈禾的理解是编剧视角，不作为她当前可发出的证言。 |
| 次日中午 | 老周把表、带和留站签验后的车票并入同一包，写套签「暴雨滞留／A-0641」。两张副联留在同号受限交接档，物品外包与受限副联异柜分存。 | 第一章货签、E06、E13。 |
| 第十天 | 沈禾单独短暂回站，出示自己早年的修表收据，录入「表主沈禾；指定领件林遥；本人决定领取，候站联系由领件人发起」并签字。林遥不在场。沈禾把公示用接收凭号给女儿，林遥认为只是旧表的事，将号夹在家中收据里。 | E03 修表收据，E04 指定领件联。留站无任何邮寄安排，关站公告是按该凭号公示。 |
| 此后至四年前 | 不记名撤离档不得按人名公示，失物包未被领取。家庭已迁离青禾，手头有领取凭号的林遥没有主动办理。出于顾虑，双方都避谈那晚的具体窗口，沈禾在林遥 21 岁时去世。 | E04 原领取约定，E15 林遥自述。 |
| T0 关站晚班 | 青禾站的关闭清点列出旧案凭号。林遥回乡核号。老周以当年经手人身份协助移交；许澄为撤下寄借给陈列柜的旧声音小样回站，认出同一场雨的带套字迹，取来自己的索引纸。玩家在失物库清点期间打开 A-0641 外包。 | 第一章开场与各章固定引入。玩家凭末班移交手册，只能按 E13 编号取带遮挡的 E14 摘录。今夜三件原物的具体归属调整来自最终处置。 |

票号用四位 0641，始终以带前导零的原样呈现。QH-283 是怀表编号。F06 中的临时住处只记录为「姨家当时住址与接领安排」，原词及门牌没有进入可播放资产。A 面留声时长 00:31。覆盖区间前后仅作两段原声保留；旁白、频谱和模型均不补写被覆盖的私人段落。
