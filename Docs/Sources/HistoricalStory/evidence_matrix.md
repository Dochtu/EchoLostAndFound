# 证据矩阵

## 证据与事实的区别

F 是编剧定案。E 是玩家可取证档的来源，其中的陈述可能只证明当事人怎么回忆。R 是规则审核过的结论。D 是可用固定按钮触发的限定披露。B 是人物的错误或夸大信念。物品可接触时生成证据卡与必要影像；过去的原件保管方式改变时，卡片和该卡带来的规则资格保留。

各组合需要表列的全部证据和玩家在固定命题里确认正确选项，输入次序不限。提交错项保留证据、进度和关系，给出具名缺项或一条只在已显示信息中取材的反馈。通过后可重复查看。任一章节开放的地点及动作在结案签发前可返回。自由对话可以提示玩家用哪个已有键，只有执行固定取证/披露动作才会入档。
