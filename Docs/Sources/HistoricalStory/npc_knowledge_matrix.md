# NPC 知识矩阵

矩阵仅供编剧和运行时按人取材。F 的完整行是作者权限，一位角色可能只知道题名下的一部分。按单个陈述判断权限。例如，「听见林母说西窗等我」和「听见林母说临时住处」是两件事。角色记得自己的情绪和玩家确认过的行动；自由输入、模型复述、证据板全局进度均不会替任何角色增加知识。

## 五种状态

| 标记 | 状态 | 运行时可用范围 |
| --- | --- | --- |
| K | 开场已知且可说 | 人物亲历或早已读过，可以在自己观察范围内讲；加「我看到／我记得」时保留来源。 |
| H | 开场已知但隐瞒 | 知道准确内容；指定披露成功前只可回避，区别于真正不知道。通过后也只可说获准的部分。 |
| B | 错误信念或夸大记忆 | 只有本人可以按主观视角表达；后台标作陈述而非 F。出现纠正触发后停用旧说法，人物可以回忆「我以前以为」。 |
| L | 后续可获知 | 开场未知。只在指定 D 动作展示获准证物或固定核对内容后进入该人物知识。另一人私谈不自动传过去。 |
| N | 在本作中永远不知道 | 当前可达状态内没有授权渠道，禁止令角色推测、确认、否认具体细节或借由玩家提供内容复述。统一给范围内的拒答。 |

未列在某人物 K、H、B、L 中的具体案情也默认 N，后续 QA 按此补测。已知私人情景可以存在于作者设定；除本表明示可披露段外，人物生成只接触允许的摘要。录音被覆盖段逐字文本、原住址、第三方完整签迹均不下发。全局结局确认后没有回到自由对话的路径，故结局的画面也不会扩展这些权限。

## 林遥

| 状态 | 可用的最小事实与条件 |
| --- | --- |
| K | F04 沈禾是母亲、背刻数字是母女两人的生日（月日）；她认得刻字的样子，未见过编号连同授权单。F05 她当年拿过纸票、没乘末班；F06 西窗与九点半的约定，亲历上联。F07 老周带她进东休息室、自己未离开，姨妈来接。F11 次晨母女见面、当周迁走和母亲去世。 |
| H | F11 她对话中的具体问答和今夜仍想要的求证。在 D06 看过 E12 与 E14 的相关文字后才能形成 E15；此前可拒谈或仅说「我更想知道西窗那一件事」。 |
| B | B03「她那晚没去西窗」，源自自己没在东室等到母亲、把次晨答话理解为母亲泛指留站找过她，仍不认为她到过西窗。D06 前允许以「我一直觉得」表达，不能装作看过西窗；D06 后改说「她去过。分开以后，我们在西窗没碰上。」 |
| L | F04 领件单的编号与授权经 E03+E04／D02 查阅后可确认。F06 母亲也试着录西窗转告，及 F08 中有一段覆盖，仅在 R03 后选择让她听余声／D04 时获知。F07 到窗的具体签时与票号经 E12+E14／D06 才能核实。 |
| N | F03 冠轴机理与拾取表盘当时的读数（她没看到表跌落）；F08 被盖的原话、私人地点是否被确切念出、按键的全过程；F10 老周独自移联的当时经过、单据上的其他乘客身份。 |

林遥可能知道姨妈旧居与家庭背景。对话只允许说家庭称谓和自己迁居，禁止据此把地址或她没亲听过的原磁带内容当物证吐出。看到 E14 仅更新签询这条，不把家人举动的原因描成她已证明的事实。

## 固定披露、修正与兜底

| ID | 固定触发 | 可以写入的内容或效果 | 兜底 |
| --- | --- | --- | --- |
| D01 核对照明 | 向老周出示 E02 | B01 停用，在本人视角允许 F02 对时点的修正；关系状态不变。 | 站台记录台「核对当班照明」可播放固定回答。 |
| D02 核对领件 | E03+E04 后选「向当事人核对领件」并指定林遥或老周 | 林遥核对授权后知道 F04 的原主／领取关系；老周可确认签单。该对话不是 R01 的额外条件。 | 柜台点「照单核对」固定台词，只有林遥实际参与收件时才更新她的知识。 |
| D03 追问表的撞击 | E01+E05 后质询老周 | 老周允许讲拾取与卡点，信息同 E05，无新证据。 | 「读当班拾取备注」给等价文字，不产生其他 NPC 的知识。 |
| D04 分别核对留声 | E07+E09 后选「核对当年检音」与老周；R03 后携 E07 选「问林遥愿不愿听余声」 | 老周只说覆写许可和范围。林遥若同意听，知道母亲说过西窗；她只听余声并看见中段「后录」标明，不听占位作目标语音，也不接触原地址。 | 两个交谈均有无模型固定选项；玩家可暂不分享，之后仍可补做。 |
| D05 核对许澄在场部分 | E07+E08+E09 后输入固定「把留声册和索引放在一起」 | 许澄按自己的目击纠正 B02，读签注后确定覆写范围，固定陈述入档 E10。 | 拒闲聊或模型异常时，许澄仍在固定核对动作当场签认，才可收 E10。 |
| D06 核对西窗签询 | E12+E14 后选「请林遥看两份记录」 | B03 停用，林遥得知西窗签字与时间；她次晨回忆入档 E15。 | 拒闲聊时仍开放「只核对两联」，林遥当场书写并签认，才可收 E15。 |
| D07 核对缺页 | E12+E13+E14 后选「请老周核对原件与副联」 | 允许老周述 F10 并入档 E16；他通过遮挡摘录知道 F07 西窗签询时间。如别的角色不在当前交互中，别的角色状态不变。 | 拒闲聊或模型异常时，老周仍在案务核对动作当场签认，才可收 E16。 |
| D08 核对是否发车 | 第三章向许澄出示 E12 的调度摘要 | 许澄知道实为停运并停用 B02，不能谈 E12 的家庭票袋数据；无论 D05 前后执行，D08 都不产生 E10 或开放覆写证词。 | 固定答「调度原令写的是停运。那晚没有恢复发车。我不能拿自己听见的声音作调度依据。」 |

备用台词只显示对应人物及已通过检查的证物文字。离线模式可完成所有令剧情前进的固定动作。玩家在自由输入中猜中时，可收到「你可以把凭据放到核对台」，不能获得本应受限的确定句、证据卡或知识更新；猜错时不改变案件日期、关系或人物知识。对来自其他 NPC 的问询使用「这段我没看到」或「那张联不在我手里」等范围内回应。
