**PARTIAL。** 本次评审对比三组 1920×1080 的实际 Game View，另检查独立拍摄的面部近景与一整段 Idle。三张 Before 与 M1.5 最终批次的对应 PNG 逐字节一致。大厅地面与雨夜湿面有所改善，人物眼睑、唇部和发际可以读出，但在原全身镜位仍低于 20/25。性能由三组独立 Player 实测另行评估。

## Idle 的解码与连续性

- 08:14:07 的采集日志记录 Station_NPC 实际 Animator 从归一化相位 0.0000 到 1.0104，模拟频率 24 Hz，输出 98 帧。Reload.log 记录有效 Humanoid、4.00 秒循环片段及 8 个蒙皮渲染单元，重开检查 Issues=0。
- 用 ffprobe 逐帧读取 Idle.mp4，再以 ffmpeg 开启解码错误中止并解码全片。视频为 H.264、1920×1080、24 fps、98 帧、4.083333 秒。98 个展示时间戳严格递增，97 个间隔均为 512/12288 秒。未发现跳时或丢帧。
- 全片缩为 960×540 灰度后，98 帧分别具有不同哈希。检查第 0、12、24、36、48、60、72、84、97 帧，可见头部与肩膀微动，鞋底没有明显位置突跳。独特哈希本身不能证明真实动作；采集脚本的逐帧 Game View 读回、Animator 相位和人物区域的变化共同支持这个判断。
- 面部区域相邻图像的平均绝对灰度差为 1.51/255，躯干为 0.21/255，动作幅度很小。该视频覆盖正常 Idle 循环，足底实际网格与地面的毫米级间距仍不能由视频测得。24 Hz 是本次录像的模拟时间步长，不能用作运行性能。
