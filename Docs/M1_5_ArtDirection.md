# M1.5 美术方向与镜位验收

候车厅的基准画面是从南端向通道尽头看去。保持原焦距、机位、固定曝光与门洞，用前景木椅的扶手、柱列的间距以及尽头透光窗形成纵深。柜台视线落在登记册和包签；怀表近景中表针、侧冠和表盖应各有清楚的边缘。

## 模型与贴图

模型以米制作，FBX 重新导入核对轴向、尺寸和材质槽。Unity 场景引用项目自己的 Prefab。近景 2K 起步，有可验证的细节收益再用 4K。Base Color 使用 sRGB，OpenGL 法线使用 Normal Map 类型，Mask 使用线性 RGBA。R 是金属度，G 是 AO，B 是细节遮罩，A 是 1 减粗糙度。无金属和环境遮蔽输入的水磨石与灰泥采用 R=0、G=1。纹理启用 mipmap、流送和各向异性过滤。

## 实机门槛

五个既有锚点以 1920×1080、High Fidelity、相同曝光记录。每项按五分计，分别评模型、材质、光照、细节及构图。大厅实拍达到 20/25 才扩展到其他区域。保留不合格的实拍和相应返工记录。性能分开记录编辑器与独立 Player。
