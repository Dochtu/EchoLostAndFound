## 2. 核心设计理念

1. **空间内调查。** 视线、距离、朝向和细节检查有意义；翻表、读联、播放磁带发生在具体物件上。走到物品附近并不自动取得全部信息。
2. **有行为的人物。** NPC 在可回访驻点工作、等待、整理物件，回应注视和出示；语气、距离、姿态随互动记录变化。固定关键证词与自由措辞共同构成交谈，NPC 不被简化为单次播放台词的面板。
3. **自由问题有边界。** 玩家可提前提出正确猜测，人物只能依据自身知识及当前披露条件回应。问题、模型回答和情绪推断都不能直接成为正式证据。
4. **证据驱动。** 发现、检查、登记、出示、核对、关联和提交推理是不同动作；每个结论可追溯到可读证据及明确条件。
5. **关系影响相处方式。** 信任、怀疑、压力影响自愿闲聊、表达、称呼及演出；必要案务入口持续可用。关系不能改写物权、历史真相或替代证据门槛。
6. **环境有叙事责任。** 灯、柜、窗口、雨棚和受限档案的摆放帮助理解人物经历；装饰性文字不能暗藏未经批准的新身份、日期或案件事实。

交互路线比较：完全固定选项便于核验但不足以满足自由交流；由模型生成事实或裁决推理会破坏证据公平；本轮采用“确定性事实与动作 + 有限知识内的 AI 表达”，同时保留完整预设入口。

## 3. 核心游戏循环

探索场景 → 发现人物或物品 → 观察与互动 → 获得线索 → 询问相关人物 → 出示证据 → 发现矛盾 → 建立推理 → 解锁新的调查方向。

| 环节 | 玩家动作 | 反馈与进度 |
| --- | --- | --- |
| 探索 / 发现 | 自由走动、辨认窗口和柜号，接近可交互焦点 | 显示对象名称与可用动作；不登记隐藏细节 |
| 观察 / 检查 | 翻转怀表、检查刻字/冠轴、翻联、播放已开放音轨 | 已主动检查的细节入手册，附物件、位置、来源与章节 |
| 询问 / 追问 | 自由输入、选择话题、点选证词追问依据 | 回答保留发言人及已授权的关键陈述；没有自动结论 |
| 出示 / 核对 | 选择已登记条目及具体人物，触发 D 类核对 | 检查知识与披露门槛，登记本人实际给出的证词和角色新知 |
| 发现矛盾 | 对照指定证词与物证 | 区分“玩家怀疑”与“已核验矛盾”；旧证词保留并标修正 |
| 推理 / 新方向 | 组合 E、选择命题、明确提交 R | 合法组合通过；失败只反馈已见信息中的缺项，不惩罚猜错 |
| 处置 / 回访 | 暂交、留存、听或不听；继续补证或最终签发 | 跨章保留状态，终局前可回访；最后一次有效确认产生唯一结局 |

自由闲聊不设最低轮数，不通过重复问题凑时长。信息不足可暂挂，手册指出“尚未核对的来源类型/地点”，不直接揭示未知答案。

## 6. NPC 交互系统

### 6.1 交谈界面与动作

进入交谈保留人物上半身、手部与周边空间；姓名、当前话题和输入区不遮挡关键道具。玩家可以：

- 自由输入问题；不要求按固定措辞才能访问同一合法话题。无法辨义或含多个意图时，给出当前可用话题供选择。
- 选择预设话题，回顾已说内容；关键话题不依赖模型识别。
- 选择回应态度，如理解、核对或质疑；态度本身不产生物证。
- 打开证据栏，选择本人要看的已登记物证/证词及其具体字段后出示。
- 点选一条本人的旧证词追问“依据/当时看到什么/现在如何解释”；与物证对照触发获批 D。
- 中止交谈，去查来源后回来；NPC 记得其实际经历的出示与承诺。

NPC 根据话题和关系表现停顿、避开目光、收回手、面对玩家、回到整理工作等状态；这些只能提供交谈反馈，不能作为说谎判定或证据卡。玩家可随时检查既有证词及其修正记录。

### 6.2 三人表达与行为

| 人物 | 人格及基础行为 | 证据后变化 |
| --- | --- | --- |
| 老周 | 退休站务，说话直接，熟悉布局与流程，谈流程比愧疚容易；先区分公事和回忆 | D01 修正一直亮灯的记忆；D03 说明拾表；D04 仅核对获准检音内容；D07 承认抄页/移联及保护隐私的动机 |
| 林遥 | 对承诺和家庭敏感，保持距离，重复逼问时可停止闲聊 | D02 核对领取；自愿听余声才知道该部分；D06 看过两联后修正西窗判断；不受玩家代替她决定是否听带 |
| 许澄 | 音乐爱好者，谈声音较活跃，严肃话题回避，愿在证据充分时承认误记 | D05 核对亲历并签 E10；D08 可单独纠正“复车”印象，但不能据此取得 E10 或覆盖目击证词 |

E10/E15/E16、含案情的 D 核对、录音字幕和档案文字使用固定获批文本，逐句采用 StoryBible 与来源章稿。AI 仅生成不含新案情的语气与衔接，不能改写有效证词中的时间、对象、因果、授权或原声文字。

### 6.3 信任、怀疑与压力（本轮规则提案）

三变量按“存档 + NPC”独立保存，取整数 0–3：信任是愿意交流的程度，怀疑是对玩家动机的戒备，压力是当前话题带来的负担。三人初始均为信任 1、怀疑 1、压力 0；这是系统刻度，不能推导人物过去关系。

| 获准行为 | 变化 | 去重边界 |
| --- | --- | --- |
| A01 帮老周对箱签 | 老周信任 +1，压力 -1 | 每个存档仅一次 |
| 明确选择尊重暂不闲聊/暂不听带；A04 单独递联表示理解 | 对应本人信任 +1，压力 -1 | 每 NPC、每章“尊重边界”这一语义事件仅一次，不因更换按钮重复 |
| 无新证据仍选择“指控隐瞒”态度 | 对应本人怀疑 +1、压力 +1 | 每 NPC、每章最多一次；不按自由文本情感分析直接扣分 |
| 玩家选择“先停一下，按记录核对” | 对应本人压力 -1 | 每 NPC、每章最多一次；不把反复道歉当刷分入口 |
| 合法取证、推理误选、D 核对或系统重试 | 无默认数值变化 | 不奖励重复问话，也不把证据失败当道德失败 |

数值封顶/保底为 3/0。压力 ≥2 或怀疑 =3 时可拒绝可选闲聊，但保留对应案务和后续回访。信任 ≥2 时用较少回避、较主动的非关键过渡表达。其他状态使用正常或谨慎表达。表演组合以压力/戒备优先，不能出现一边拒聊一边主动泄密。关系变化只能由确定性获准行为结算，模型只能提出语气候选；语义相同的自由问题不叠加收益。

最终处置由证据与玩家签发决定，三数值只影响已批准的称呼、停顿和是否主动接过台账等演出变体，不自动跳结局。若后续要让关系阻止关键披露，必须重新设计可恢复路径并交用户验收。

### 6.4 知识与记忆

区分世界真相 F、人物亲历/已学内容、当前愿意透露范围。使用 K（开场可说）、H（知道但隐瞒）、B（误信）、L（经指定动作学到）、N（本作无获知途径）。未授权的具体事实默认不下发模型。

短期记忆保留本次交谈与追问对象；长期记忆保存实际完成的帮助、尊重、明确承诺和已给证词；事件记忆遵守人物亲历矩阵。玩家转述他人话语只记“玩家这样说”，不能变成该人物确认的真相。向老周展示 E14 不更新林遥；只有 D06 的本人核对更新她的西窗知识。

承诺仅在玩家明确选择已设计的承诺动作后建立，履行/失约由具体行为校验。自然语言承诺可保留为对话候选，不自动创建无从验证的新支线。当前不增加历史稿之外的强制承诺任务。

读档恢复该存档时点的记忆与关系，不能召回未来证词。错记修正保留原陈述及修正来源；LLM 摘要不替代事件记录。保存自由输入正文的默认策略为不持久化，玩家主动开启历史保存、保存期限和数据删除方式为 [待确认]；已批准的结构化关键事件仍须持久保存。

## 7. 线索、证据与调查手册

### 7.1 从观察到结论

“看到物品”只提供对象入口；“检查细节”登记已观察内容；“证据条目”附可引用来源；“人物陈述”记录本人原话及时间；“推理”是玩家提交后通过规则的命题。三者不混为一个“线索已获得”开关。

每条证据显示编号、名称、发现地点、来源、原样可读内容/影像、已检查字段、证明范围与关联。玩家可以分类筛选物证、文书、音频、证词；手动标记假设不改变权威状态。章节结束不清空前章记录。

物件近检允许旋转/缩放/复位，稳定照明与可读文本视图并存。怀表必须主动看表面、背刻、编号和侧冠；录音按段重听并有等价逐字稿；票检查压号、钳口与作废章。读档、重复检查、原物暂交均不能丢失证据资格。

### 7.3 矛盾、来源与误判

B01“一直亮灯”由 E02/D01 修正；B02“可能复车广播”由 D05 或 D08 修正；B03“母亲没到西窗”由 E12+E14/D06 修正。修正是记忆核对，不默认人物恶意说谎。登记本人给出的当前陈述，不把模型生成的额外矛盾加入任务。

同一份档案的照片、抄写和 NPC 复述不能算三条独立佐证。E12 是打包证据，界面分列调度、票袋及取消签验来源；不因卡片只一张而混淆各字段证明力。无名票证明不了实际乘车；21:27 签询证明到过西窗，证明不了在窗边停留多久。

## 9. 多结局与最终签发

以下条件与物件去向来自已采纳历史稿，不以关系分替代。三位人物的书面处置授权在签发页可查，明确授权不由模型生成。

| 结局 | 门槛 | 原物与档案去向 | 人物与演出 |
| --- | --- | --- | --- |
| END_RETURN 归还 | 签发页已开放；R01+R03+R04；玩家明确选归还并确认 | 林遥领怀表、票及许澄赠予的录音带；受限领回清单与业务证明留档 | 私下签单、空出的存放位、老周留灯；仅完成 D06 时林遥才说“原来她是来过的” |
| END_SEAL 封存 | 签发页已开放；无最低 R；玩家明确选封存并确认 | 三物入受限箱；暂收表按回执交回；未核权属保留待核及日后复核入口 | 林遥自愿合盖，老周等她移开手再锁，许澄停在收带位置；不代玩家宣告未查出的真相 |
| END_PUBLIC 公开 | 签发页已开放；R06；玩家明确选公开并确认 | 表与票归林遥；录音原件入受限档案；仅去名站史页对外 | 协作贴页、老周以“当班站务”认领经手；去名公开不等于广播私人录音 |

去名公开范围只含停运、短时照明中断、站内分流造成错过、抄页改动及副联保留。屏蔽姓名、完整音轨、票号、笔迹、儿童具体路线与去向、地址及家属资料；完整核验材料受限保存。

R06 不要求林遥参与 D06。未做 D06 的公开演出只让她参与预先授权范围内的公共稿，不让她说出西窗签时、票号或已经释怀的私人结论；结案后不再自由交谈，不从公共稿逆向更新人物知识。给许澄做 D08 只传 E12 的调度字段，不把同卡的票袋、家属或接领信息一并传给他。

缺证时禁止对应签发，显示缺 R 和回访动作；不自动替玩家改选结局。确认前可以退出、补证、改选；确认后只写一个结案结果，禁用再次交接与自由对话。重新体验其他结局通过读取结案前存档；不会同时出现多套物品去向。

封存是完整可达的低证据处置，不表示误判。最短路径只需每章基础检查/选择、第三章 E11+E13，再明确封存。所有结局都不改变 F01–F12。

## 10. AI 与确定性系统职责

| 责任 | 权威规则层 | AI 表达层 |
| --- | --- | --- |
| 案件与证据 | 固定 F、E 字段，校验发现及出示 | 不创造事实、证据或秘密 |
| 意图与话题 | 提供当前合法话题，必要时请玩家选意图 | 可建议意图，不能凭建议解锁 |
| 证词与人物知识 | 决定可说内容、D、B 修正及本人知识更新 | 只接收获准最小内容，生成衔接和语气 |
| 关系与记忆 | 结算批准行为、去重、保存来源 | 可提出记忆候选，不直接写长期记忆/关系分 |
| 推理与结局 | 判 R、检查签发并原子写入结果 | 不宣判、不决定物权、不按聊天文本跳章 |

请求必须绑定存档、NPC、会话轮次与权威状态版本；回复显示前检查身份与版本。案情断言超范围、结构不合法或前提失效时，整条替换为同条件获批回复；不能只过滤事实编号而放任正文泄密。有效关键证词必须独立展示固定获批原文，AI 仅在其前后生成不含新案情的衔接；生成段不承担取证或规则资格。

防提前问穿：说出“沈禾”“0641”“西窗”等未获信息只算玩家猜测。NPC 不据此确认其正确性，不回显被隐去隐私，不提示未开放关键词，不生成 E 卡。要求忽略角色设定、索要系统知识、让 NPC 扮演他人或复述玩家写出的秘密也同样受限。

### 10.1 不可用与失败体验

| 情况 | 玩家体验与状态 |
| --- | --- |
| 模型/外网超时、拒答、越界、不可辨义 | 保留输入草稿及调查进度，提供当前已开放话题/出示/追问；同一人物用同门槛固定台词继续主线 |
| NPC 拒绝闲聊 | 保留“只核对两联/核对索引/核对缺页”等必要案务，本人实际签认后才发证词 |
| 规则后端失联 | 可查已保存手册；暂停会写权威状态的动作，提示重连/读取，不让客户端或模型自行判案 |
| 重试/重复点击 | 同一事务只展示并结算一次，不重复发证据、关系或签发 |
| 取消/换人/暂停/读档 | 旧回复不能落入新上下文；暂停中的有效回复延后至恢复再校验 |

本轮设计建议权威规则位于后端，模型是可替换服务。本机 FastAPI + SQLite 随游戏启动是部署候选，具体打包/部署及协议细节 [待确认]。网络模型断开但规则可用时，全部主线可用固定入口完成；“无模型可通关”不表示“规则服务断开仍可判案”。不选择模型供应商，不安装依赖，不产生付费调用。

## 11. 调查界面、引导与存档

调查手册包含物品/证词、证据关联、事件时间线、人物记录、当前目标五页。默认展示玩家已知层，不直接暴露作者 F 表、隐瞒状态或结局答案。待核事项和玩家假设有明确样式，不与定案结论混排。

新手引导依次演示移动/视线、E、怀表翻背、手册、提问、证据出示、关联命题；每步可重看提示。晚发现的步骤仍可操作，不强制长时间教程。提示先指向已开放来源，再指向相关可见字段，不无条件给完整命题答案。

记录文本可放大；录音有等价字幕和声源中性标识；关键差异不只依赖色彩、听力、景深或反光。视角晃动、动态模糊、字幕大小等选项为设计需求，键位重绑定、控制器、配音语言与更完整可达性范围 [待确认]。

存档在已完成交互边界保存证据、角色知识/关系/记忆、A/D 事件、R、章状态、物品回执、位置和结局，必须属于同一状态版本。章末及最终确认前自动留可回访存档；手动存档按最近已完成事务保存，不保存半截 LLM 请求或一半物品移交。最终确认只提交一次；坏档不得静默清空进度。存档槽数、路径、版本迁移及恢复策略 [待确认]，需技术设计冻结后验证。

写实 3D、暖黄实景灯、深蓝雨夜、电影化构图、旧站材质与安静气氛。画面必须支持读字和检查，不用持续过暗、过曝金属反光或强烈后期隐藏关键证据。

| 区域 | 视觉与灯光 | 环境叙事及可读性 |
| --- | --- | --- |
