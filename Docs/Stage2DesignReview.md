# 阶段 2：GDD 与 StoryBible 设计审查报告

日期：2026-11-21。负责人：Game Director。状态：本阶段文档整合与独立静态 QA 已完成，提交用户验收；没有自行批准下一阶段。

## 目标与交付结论

按原始故事和用户确认沿用的历史完整剧情，形成统一的 Unity HDRP 第一人称 3D 调查设计。GDD 负责玩家操作、调查循环、NPC/AI、场景、关系、反馈与验收；StoryBible 负责真相、人物、知识、证据、章节与结局。关键剧情条件可追溯，未因技术升级重写故事。

完整原案在当前工程初查时缺失，因此先暂停正式剧情。随后从早期项目只读聊天中的两次完整读取结果恢复 V1.0，并在实际存在的历史导出目录找回八份扩写文件。用户明确选择“沿用历史完整剧情稿，保留来源并改为 Unity 3D（推荐）”后，才将其纳入本版。恢复过程、原文件名与哈希详见[来源登记](Sources/README.md)。

当前策划可作为后续工作拆分与技术设计的依据。制作参数、目标硬件、资源/配音来源、部署与存档技术细节仍标 [待确认]；这些缺项不能由 Agent 在制作时悄悄决定。用户原任务在“每章明确……场”处截断，未收到的余下要求也保留待确认。

## 已完成的设计

- 3D 区域连接建议为失物招领处 ↔ 候车大厅 ↔ 站台安全内侧。东室、西窗、档柜仍在三个主要区域内表达；各章按条件开放，终局前允许回访。
- 检查动作区分看到、主动检查、证据入档、出示、本人核对、提出矛盾及提交推理。照片/复本保持来源，不能重复计算独立性。
- 自由问答、预设话题、态度选项、出示、追问共存；关键案务与证词使用固定获批文本，AI 只生成不含新案情的衔接。
- 每名 NPC 的知识、信任、怀疑、压力和事件记忆独立；关系刻度与动作去重为本轮待验收规则建议。关系影响表演和可选交流，必要案务不被永久封死。
- 沿用故事确定的三种处置：归还需 R01+R03+R04，封存无最低 R，公开需 R06；均需先开放签发页并由玩家明确唯一确认。
- 模型不可用且规则可用时，固定入口支持主线；后端失联时暂停权威变更。部署方案尚待技术设计，不把“无模型”混同于“无规则系统”。

### 独立 QA：纸面路径与条件枚举

QA 先通读全部来源，再比对终稿并读回修订。没有发现遗留的阻塞性剧情或推理问题。代表路径为：

| 路径 | 必要动作摘要 | 结案条件 |
| --- | --- | --- |
| 最短封存 | E01 → A02 装袋；E06+E07 → A03 留文字；E11+E13 → 签发页 | 主动选封存；最少五张 E 卡，无需任何 R |
| 归还 | 上述开章、签发前置；补齐 R01、R03、R04 所需材料；D05 本人签认 E10 | 最少十二张 E 卡；只交付合法三物，留受限清单 |
| 公开 | R01–R05 全通过并完成正确排序 R06；保留 D07 本人签认 | 最少十五张 E 卡（E01–E14、E16），E15 可选 |

QA 在内存中枚举 65,536 种 E 子集，从来源声明提取 R/结局条件并筛选章节与取证前置，假定正确执行必要提交和最终选择：签发页可持有的 420 组里，全部能封存，12 组能归还，2 组能公开，公开两组只差 E15。归还和公开不是与封存互斥的“可选资格”；只有最终签发值互斥。此为设计条件模型，不是游戏程序、自动化测试套件或玩家试玩。

已专门检查：E10 与 D05 无循环；D05/D08 任序；E15 不在必需推理闭包；R04/R06 不要求林遥 D06；机械表不因停电停走；覆盖原声不可恢复；21:27 签询不能证明全部停留时长；同源复本不算独立佐证。

## 未验证、风险与下一步

本阶段没有启动 Unity、Play Mode、Windows 构建、后端、真实模型或外网 API；没有制作或导入美术/音频。因此第一人称手感、交互遮挡、实际中文输入、人物演出、模型事实约束、存读档、断线重试、真实通关、画面/可达性/帧率和 34 分钟节奏均为“尚未验证”。GDD 的 AC01–AC15 是后续运行要求。

TechnicalDesign 与 TestPlan 仍为占位，未在本轮写成已实现的接口或测试。目标硬件、资源预算和来源授权、具体当代年份/服装/肖像/配音、空间尺度、部署打包、存档恢复及数据保留策略仍 [待确认]。这些项目需在对应阶段由指定唯一写入者细化。

版本管理未进行 git add、git commit、推送、重置、清理、全局设置或 LFS 规则变更；当前工作树已有文件整体未跟踪，不能凭普通 git diff 为空证明所有文件均未改变。本报告依据本轮明确分配与写操作清单报告范围。

建议下一步先由用户验收两份主稿和本轮设计提案；验收后的后续任务另行确定目标、技术契约、测试计划与首个原型范围。本轮停在文档交付，不自动进入开发。
